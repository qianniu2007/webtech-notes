CSS: Dressing up the skeleton

CSS stands for Cascading Style Sheets. Colors, font sizes, spacing, layout, animation, and "switching to a stacked layout on a phone" — all of it comes from CSS.

Basic Syntax

A rule: a selector plus a set of declarations

style.css 
/* selector { property: value; } */
p {
  color: teal;
  font-size: 16px;
  margin: 0;
}

Where can CSS live?

  • External stylesheet: a separate .css file linked in (used here, easiest to maintain)
  • Internal styles: written in a style tag in the page head
  • Inline styles: the element's style attribute, high priority but not for overuse
Selectors

Select first, then style

SelectorSyntaxWhat it selects
Tag selectorp { }All p tags
Class selector.card { }Elements with class="card"
ID selector#top { }The element with id="top" (unique per page)
Descendantnav a { }All a inside nav
Pseudo-classa:hover { }A link while the mouse hovers
Cascade and specificity When several rules hit one element, the more specific one wins: inline > ID > class > tag; at equal specificity, the later rule applies. This is what "cascade" means.

Grid

Two-dimensional layout, like drawing a table

Flexbox handles one row, while Grid manages rows and columns together. The card grids on this site use Grid with repeat(auto-fit, minmax(...)), so they reflow as the screen narrows.

grid syntax 
.grid {
  display: grid;
  grid-template-columns:
    repeat(3, 1fr);
  gap: 24px;
}
Responsive

One codebase, adapted to phones

A media query @media can detect screen width and, on narrow screens, turn three columns into one and collapse the nav into a hamburger menu.

media query 
@media (max-width: 720px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Narrow the browser window and this site reshapes in real time, so you can verify it at once.

Summary CSS gives the page its looks and adaptability. But it is still static — to make the page respond to clicks and change live, JavaScript is needed.
