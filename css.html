CSS：给骨架化妆

CSS 全称 Cascading Style Sheets（层叠样式表）。颜色、字号、间距、排版、动画，以及"手机上自动变竖排"，全靠它。

基本语法

一条规则：选择器 + 一堆声明

style.css 
/* 选择器 { 属性: 值; } */
p {
  color: teal;
  font-size: 16px;
  margin: 0;
}

CSS 可以写在哪？

  • 外部样式表：单独 .css 文件，用 link 引入（本网站采用，最好维护）
  • 内部样式：写在页面 head 的 style 标签里
  • 行内样式：元素的 style 属性，优先级高但不推荐滥用
选择器

先选中，再改样式

选择器写法选中谁
标签选择器p { }所有 p 标签
类选择器.card { }class="card" 的元素
ID 选择器#top { }id="top" 的元素（页面唯一）
后代选择器nav a { }nav 里面的所有 a
伪类a:hover { }鼠标悬停时的链接
层叠与优先级 当多条规则同时命中一个元素，按"谁更具体听谁的"：行内样式 > ID > 类 > 标签；同样具体时，写在后面的生效。这就是"层叠"的含义。

每个元素都是一个"四层盒子"

从里到外：内容 content → 内边距 padding → 边框 border → 外边距 margin。拖下面的滑块，看盒子怎么撑大。

Grid 网格布局

二维排版，像画表格

Flexbox 管一排，Grid 同时管行和列。本网站的卡片网格就是用 Grid 加 repeat(auto-fit, minmax(...)) 做的，屏幕变窄会自动换行。

grid 写法 
.grid {
  display: grid;
  grid-template-columns:
    repeat(3, 1fr);
  gap: 24px;
}
响应式 Responsive

一套代码，适配手机

媒体查询 @media 可以判断屏幕宽度，在窄屏时把三列改成一列、把导航收成汉堡菜单。

媒体查询 
@media (max-width: 720px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

把浏览器窗口拖窄，本网站就会实时变形，可以马上验证。

小结 CSS 让页面有了颜值和自适应能力。但它还是"静止"的——想让页面响应点击、实时变化，就得请出 JavaScript。
