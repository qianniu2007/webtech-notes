四个模块，搭起整个前端

网页说到底就三件事：HTML 负责骨架，CSS 负责长相，JavaScript 负责让它活起来。下面按顺序点开就行。

H

HTML 结构

标签、语义化、表单与链接，用正确的标签讲清楚页面每一块是什么。

选择器、盒模型、Flexbox 与 Grid，再加上手机端自适应的响应式布局。

进入 CSS 篇
J

JavaScript

变量、函数、DOM 与事件，写几段真正能响应点击和输入的小程序。

进入 JS 篇

Git 与上线

成长轨迹

我是这样一步步学过来的

第 1 阶段 · Web 基础

搞懂网页是怎么跑起来的

HTTP、DNS、客户端与服务器，浏览器输入网址后到底发生了什么。

第 2 阶段 · HTML

用标签搭出页面骨架

文档结构、文本、链接、图片、表格、表单，以及语义化写法。

第 3 阶段 · CSS

让页面变得好看又自适应

层叠与优先级、盒模型、Flexbox、Grid 和响应式媒体查询。

第 4 阶段 · JavaScript

给网页装上"反应神经"

变量类型、函数、DOM 操作与事件监听，页面开始响应我的操作。

第 5 阶段 · Git & 上线

把代码托管并发布出去

Git 提交、推送到 GitHub，开启 GitHub Pages 得到真实网址。

现在 · 这个网站

把所学整理成自己的作品

独立完成五个页面、多个交互演示，并持续在 GitHub 上更新。

小提示：怎么用这个网站？ 建议按 HTML → CSS → JavaScript 的顺序读。每个页面都有深色代码块和"演示框"，代码可以一键复制，演示可以直接动手玩。
