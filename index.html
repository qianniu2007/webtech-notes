More than just notes

Every concept can be checked on the spot

I don't like tutorials you can only read. So every demo here is real: drag a slider to see how the box model changes, or click a button to watch JavaScript update the page. Whether you've learned it, your hands will tell you right away.

  • Semantic HTML: header, nav, main and article each do their own job
  • Responsive layout: reads well on both laptops and phones
  • Real interaction: menus, a counter, a color picker and a to-do list
  • Full Git history: recording how the site grew step by step

Growth Path

How I got here, one step at a time

Stage 1 · Web Fundamentals

Understanding how a web page runs

HTTP, DNS, client and server, and what happens after you type a URL.

Stage 2 · HTML

Building the page skeleton with tags

Document structure, text, links, images, tables, forms and semantic markup.

Stage 3 · CSS

Making the page beautiful and adaptive

Cascade and specificity, the box model, Flexbox, Grid and responsive media queries.

Stage 4 · JavaScript

Giving the page its "reflexes"

Variable types, functions, DOM manipulation and event listeners, so the page responds.

Stage 5 · Git & Deploy

Hosting and publishing the code

Git commits, pushing to GitHub and enabling GitHub Pages for a real address.

Now · This site

Turning everything into my own work

Independently building five pages, multiple demos and updating on GitHub continuously.

Tip: how to use this site? Read in the order HTML → CSS → JavaScript. Each page has dark code blocks and demo boxes; code can be copied with one click and demos can be played with directly.
