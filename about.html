关于这个项目

一个学生为了"把知识真正学会"而做的学习成果展示网站。这里讲清楚它是什么、为谁做、怎么一步步建起来。

它是什么

一份能动手玩的学习档案

这是我在 Web Technologies 课程结束后，独立整理的个人项目。它不是把课件复制一遍， 而是用自己的话把 HTML、CSS、JavaScript 重新讲清楚，并且每个知识点都配上真实代码和可交互演示。 能讲给别人听、还能当场演示，才算真的学会了。

它为谁做

首先是为未来的自己

第一读者是我自己：方便日后随时回查学过的概念。其次是和我一样刚入门的同学， 以及想了解我学到了什么的老师。所以我尽量把话说通俗，少用吓人的术语， 遇到术语也会立刻用大白话解释。

技术栈

只用最基础的三件套，不依赖框架

刻意不使用 Vue、React 等框架，目的是把基本功练扎实。整个网站没有后端、没有数据库，刷新不会丢失任何重要数据。

H

HTML5

语义化标签组织五个页面，结构清晰、可访问。

C

CSS3

变量、Flexbox、Grid、动画与媒体查询，纯手写。

J

JavaScript

原生 JS 操作 DOM、监听事件，无任何依赖库。

G

Git & Pages

Git 记录历史，GitHub 托管，Pages 提供网址。

构建流程（我是怎么做的）

第 1 步

先定主题与四个页面

确定"学习成果展示"方向，列出每页要讲什么，避免做到一半越做越大。

第 2 步

设计统一视觉系统

在 style.css 里用变量定好配色、字号、圆角和阴影，保证全站风格一致。

第 3 步

逐页写内容与演示

语义化 HTML 搭结构，再写交互脚本，让每个演示都能真实响应。

第 4 步

做图标、提交、上线

生成 favicon、app icon 和封面图，用 Git 分阶段提交，推到 GitHub 并开启 Pages。

如何上线

GitHub Pages，免费又简单

代码推送到 GitHub 公开仓库后，在仓库 Settings → Pages 里选择 main 分支， 稍等片刻就能得到一个 https://用户名.github.io/仓库名/ 的真实地址。 以后每次 push，网站都会自动更新。

持续更新 这个项目会一直跟着我的学习进度走：学到新东西，就回来补一页、加一个演示，并用 Git 记录下来。
