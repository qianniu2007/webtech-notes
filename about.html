About this project

A student's learning journal built to truly master the knowledge. Here is what it is, who it is for and how it was built step by step.

What it is

A learning journal you can play with

This is the personal project I put together after the Web Technologies course. Rather than copying the slides, I explain HTML, CSS and JavaScript in my own words, backing every topic with real code and interactive demos. Being able to explain it to someone else and demo it on the spot means I have truly learned it.

Who it is for

First of all, my future self

The first reader is me, so I can look up concepts later. It is also for classmates who are just starting out, and for teachers who want to see what I learned. That is why I keep the language plain, explain jargon in simple words right away and avoid intimidating terms.

Tech Stack

Only the three basics, no framework

I deliberately avoid frameworks such as Vue and React, so the fundamentals are solid. There is no back end and no database, so nothing important is lost on refresh.

H

HTML5

Semantic tags organize the five pages, clear and accessible.

C

CSS3

Variables, Flexbox, Grid, animation and media queries, all hand-written.

J

JavaScript

Vanilla JS for the DOM and events, with no dependency libraries.

G

Git & Pages

Git records history, GitHub hosts it and Pages provides the address.

Build process (how I did it)

Step 1

Choose the topic and four pages first

Settling on the learning-journal direction and listing what each page covers, so the project doesn't grow out of control halfway.

Step 2

Design a unified visual system

Using variables in style.css to set colors, font sizes, radii and shadows, keeping the whole site consistent.

Step 3

Write content and demos page by page

Building structure with semantic HTML, then writing the interaction scripts so every demo responds for real.

Step 4

Make icons, commit and go live

Generating the favicon, app icon and cover, committing in stages, pushing to GitHub and enabling Pages.

How it goes live

GitHub Pages, free and simple

After pushing the code to a public GitHub repository, choose the main branch under Settings → Pages. After a short wait you get a real address like https://username.github.io/repo/. Every push after that updates the live site automatically.

Continuously updated This project keeps following my learning progress: when I learn something new, I come back to add a page or a demo and record it with Git.
