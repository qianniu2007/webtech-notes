JavaScript: Bringing the page to life

HTML is the skeleton and CSS is the looks; JavaScript (JS) is the "reflex". A button that changes something, input that updates live, a page that moves — JS is behind all of it.

Variables & Data Types

Giving data a name with variables

Declarations 
let name = "Sam";        // Can change
const year = 2026;        // Cannot be reassigned
var old = 1;             // Old syntax, rarely used now

let isStudent = true;    // Boolean
let scores = [90, 85];    // Array

Functions

Pack a piece of logic and reuse it

Function syntax 
// A normal function: takes arguments, returns a result
function add(a, b) {
  return a + b;
}
add(2, 3);  // 5

// Arrow function (a more concise form)
const square = x => x * x;
square(4); // 16

A function is like a small machine: feed arguments in, it processes them inside, and gives back a result. Write the logic once and call it anywhere, avoiding repeated code (the DRY principle).

The core idea of event-driven code The most common pattern on a web page is: "when the user does something (click, input), call a function". All three demos below follow this pattern.
DOM & Events

How does JavaScript change the page?

The browser organizes the page into a "DOM tree"; JS can find nodes, change content and add styles, then listen for user actions with addEventListener. The three apps below are the best examples.
