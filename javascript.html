JavaScript：让网页活起来

HTML 是骨架，CSS 是长相，JavaScript（简称 JS）则是"反应神经"。点按钮弹出变化、输入实时更新、页面动起来，背后都是它。

变量与数据类型

用变量给数据起名字

变量声明 
let name = "小明";      // 可改
const year = 2026;      // 不可重新赋值
var old = 1;           // 老写法，现在少用

let isStudent = true;  // 布尔
let scores = [90, 85];  // 数组

函数 Function

把一段逻辑打包，反复调用

函数写法 
// 普通函数：接收参数，返回结果
function add(a, b) {
  return a + b;
}
add(2, 3);  // 5

// 箭头函数（更简洁的写法）
const square = x => x * x;
square(4); // 16

函数就像一台"小机器"：从入口喂进参数，它在内部处理，最后吐出一个结果。 同样的逻辑写一次，就能在任意地方调用，避免重复代码（DRY 原则）。

事件驱动的核心思路 网页里最常见的模式是："当用户做了某件事（点击、输入），就调用某个函数"。下面三个演示全是这个套路。

JavaScript 怎么改网页？

浏览器把页面整理成一棵"DOM 树"，JS 能找到节点、改内容、加样式，再通过 addEventListener 监听用户动作。下面三个小应用就是最好的例子。

事件监听的典型写法 
const btn = document.getElementById("plusBtn");
btn.addEventListener("click", function () {
  count = count + 1;
  document.getElementById("counterDisplay")
    .textContent = count;   // 改 DOM，页面立刻更新
});
