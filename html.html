HTML：网页的骨架

HTML 全称 HyperText Markup Language（超文本标记语言）。它不负责好看，只负责告诉浏览器：这里是标题，那里是段落，这张是图片，那个是按钮。

基础概念

标签就是一对"括号指令"

大多数 HTML 元素由开始标签和结束标签组成，内容夹在中间。结束标签多一个斜杠。

标签结构 
<p>这是一段文字</p>
<!--  ↑开始标签    内容    ↑结束标签 -->

<h1>一级标题</h1>
<a href="https://example.com">一个链接</a>

像 <img>、<meta> 这种没有内容的元素叫"空元素"，不需要结束标签。

浏览器实际渲染出来

一级标题

这是一段普通文字。

一个可点击的链接
属性是给标签的"附加说明" 比如 href 告诉链接往哪跳，src 告诉图片去哪找，写成 名="值" 的形式放在开始标签里。
文档结构

每个网页都有固定的"四件套"

文档骨架 
<!DOCTYPE html>            <!-- 声明：这是 HTML5 -->
<html lang="zh-CN">   <!-- 整页的根，语言标中文 -->
<head>
  <meta charset="UTF-8">  <!-- 字符编码，避免乱码 -->
  <title>浏览器标签上的名字</title>
</head>
<body>                <!-- 用户能看到的一切都放这里 -->
</body>
</html>

<head> 头部

用户看不见，放给浏览器和搜索引擎看的信息：编码、标题、图标、样式表和分享卡片。

<body> 主体

页面上所有看得见、点得到的内容，都写在 body 里面。

嵌套关系

标签可以一层层套，但要"先开后关、成对闭合"，就像括号不能交叉。

语义化 HTML

用对标签，比用 div 包一切更重要

语义化就是"见标签知用途"：导航就用 nav，文章就用 article。机器读得懂，盲人的读屏软件也读得懂。

<header> 站点头部 + <nav> 导航
<main> 主要内容
<article> 独立文章
<aside> 侧边栏
<footer> 页脚信息
  • header / footer：页面或区块的头尾
  • nav：导航链接集合
  • main：页面独一无二的主内容
  • article：可独立成篇的内容，如一篇帖子
  • section / aside：内容分区 / 旁注侧栏
为什么要这么讲究？ 同样的视觉效果，语义化标签让搜索引擎更容易理解你的页面，也让使用读屏器的人能顺畅浏览——这就是网页的"可访问性"。
常用元素

文本、列表、图片与链接

列表与图片 
<!-- 无序列表 -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<!-- 图片：alt 是加载失败时的替代文字 -->
<img src="photo.jpg"
     alt="一张照片">
标签用途
h1–h6六级标题，h1 一页通常只有一个
p段落
ul / ol无序 / 有序列表
a超链接，靠 href 指定地址
img图片，靠 src 指定文件
strong / em强调 / 斜体强调
表单 Form

收集用户输入的标准方式

表单本身只负责"长什么样"，真正处理数据通常要后端；本项目不连服务器，所以下面只展示结构。

form 示例 
<form>
  <label>昵称
    <input type="text"
           placeholder="请输入">
  </label>
  <input type="checkbox"> 记住我
  <button type="submit">
    提交
  </button>
</form>
